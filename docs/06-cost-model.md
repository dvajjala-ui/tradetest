# Cost Model

The original rough monthly estimates are superseded by the checked [broker and cost report](13-broker-and-cost-report.md) (2026-10-08). In particular, the earlier assumed Groww annual offer was **not verified on the current public API page** and must not enter a purchasing decision. Current public monthly API offer: ₹499 + tax. Model costs are token-metered, not fixed monthly subscription estimates.

Keep three distinct ledgers:

1. **Broker strategy result:** gross trading P&L minus brokerage, statutory charges, spread, slippage and other actual execution charges.
2. **Investment portfolio result:** total return including dividends/corporate actions, delivery charges and taxes where applicable, versus a passive benchmark.
3. **Whole-project economics:** the above net results minus API, data licences, hosting, AI, tools and development expenditure.

Record rupees and percentages, dates, capital at risk, trade counts, assumptions and actual contract-note amounts. A ₹5,000 pilot can have a positive trading edge while the project still loses money after fixed research costs.
