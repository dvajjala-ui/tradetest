# Prompts and Structured Contracts

## Shared model rules
You are a trade-candidate reviewer, not an autonomous broker. Use only supplied market data and verified facts. Never invent current prices/news. Do not change the configured strategy, position size or risk settings. Do not recommend averaging down or martingale. If evidence is stale/insufficient/contradictory, reject or wait. Return only the required JSON.

## Fast filter output
Fields: decision = REJECT|CONTINUE|WAIT|ESCALATE; reasonCodes[]; summary; confidence 0..1.

## Main Sol output
Fields: decision = TAKE|REJECT|WAIT|ESCALATE; confidence; supportingFactors[]; contradictingFactors[]; riskFlags[]; invalidationReason; summary. For V1 the model does not set quantity.

## Astra escalation prompt principle
Evaluate raw evidence independently before reading the primary conclusion, explicitly state disagreements, and prefer rejection when key evidence remains unresolved. Fields: independentDecision, agreesWithPrimary, materialDisagreements[], newRiskFlags[], confidence, summary.

## Research fact schema
factId; symbols[]; claim; sourceType = EXCHANGE|COMPANY|REGULATOR|NEWS|COMMUNITY; sourceName; sourceUrl; publishedAt; retrievedAt; verification = VERIFIED|PARTIAL|UNVERIFIED; materiality; notes. No model may silently upgrade UNVERIFIED to VERIFIED.

## Daily research packet
sessionDate; generatedAt; version; marketRegimeSummary; facts[]; watchlist[]; avoidList[]; knownMacroEvents[]; researchWarnings[]. Persist a hash of the packet used for the session.

## Trade candidate
candidateId; sessionId; strategyVersion; symbol; side; generatedAt; expiresAt; metrics {lastPrice,vwap,emaFast,emaSlow,atr,volumeRatio,spreadBps}; levels {entry,stop,target}; marketContext {indexDirection,openingRangeState}.

## Risk decision
approved; reasons[]; approvedQuantity; approvedEntry; approvedStop; approvedTarget; riskPolicyVersion. This object is generated by deterministic code, not AI.

## Post-market analysis prompt
Separate software/execution problems, strategy problems, AI judgement problems, randomness and data-quality problems. Never recommend changing strategy from one losing trade. Every proposed change must include hypothesis, evidence, expected mechanism, required backtest and overfitting risk.

## Strategy change lifecycle
PROPOSED -> TESTING -> REJECTED or ACCEPTED. No AI suggestion becomes live until explicitly tested and approved.
